# Dental Clinic Website Concepts — 10 Template Pack

Open `index.html` in a browser for the gallery, then choose any concept to open its standalone website.

## Included
- 10 visually distinct, responsive dental clinic landing-page concepts.
- Each template is a standalone `index.html` with embedded CSS, SVG artwork and small JavaScript interactions.
- Responsive mobile navigation and a demo appointment form confirmation.
- No external image, font, CSS or JavaScript dependencies.

## Important demo notes
All clinic names, providers, reviews, contact details, addresses and opening hours are fictional placeholders. The appointment form does not submit or store information. Before any real launch, replace all sample content, confirm clinical claims with the clinic, add approved photography, connect a secure appointment workflow, and add the clinic's privacy, accessibility and legal information.

## Preview
Open `index.html` locally in Chrome, Edge, Firefox or Safari.
